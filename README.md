# Embodied Terminal-Bench review evidence

Companion downloads for the [task review website](https://robo-si-review.wuxiyang.chatgpt.site). This asset-only repository contains files selected for the public task pages. The implementation repositories retain their existing access settings.

[Download index and SHA-256 manifest](https://github.com/wuxiyang1996/robo-si-review-assets/releases/download/site-evidence-20261028/external-evidence.json) maps original website paths to immutable release assets, byte counts and SHA-256 digests. Uploaded bytes are unchanged; this migration does not downsample trajectories or alter physical evidence. Website videos remain on the website.

A file being published here does not mean its task succeeded. Individual task pages distinguish complete valid runs, incomplete plans, physical failures and startup errors, and provide the expert, high/low plans, trajectory correspondence and verification scope.

The download names encode the original path using `--`. Use the manifest's original `path` when restoring a directory tree. The dated release is an evidence-hosting snapshot, not a benchmark software release.
